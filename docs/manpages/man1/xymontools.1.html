NAME

xymontools, xymonloadhosts, xymonstackio, xymonavailability, xymonlocator, xymonnetprobe - Xymon diagnostic tools

 

SYNOPSIS

xymonloadhosts HOSTSFILE HOSTNAME [HOSTNAME...]
xymonloadhosts @ HOSTNAME
xymonstackio FILENAME
xymonavailability HISTFILE STARTTIME ENDTIME
xymonlocator IP:PORT
xymonnetprobe [--debug] [--timeout=N] [--concurrency=N] IP/PORT/TESTSPEC[@SOURCEIP]...

 

DESCRIPTION

These programs run one piece of the Xymon server by hand, using the same code as the daemons, to show what that piece makes of a configuration file, a history file or a network service. They are installed only by "make install-tools", not by "make install".

Each one prints its usage with --help. Run them under xymoncmd(1) so that they find the server's configuration.

xymonloadhosts
Loads HOSTSFILE the way the server does, including its "include" and "directory" lines, and prints every item of each HOSTNAME's entry, after resolving the name to its canonical host. With "@" it shows the entry xymond holds for HOSTNAME instead. It then prompts: an item name prints that item, an empty line moves on to the next host.
xymonloadhosts /etc/xymon/hosts.cfg www.example.com

xymonstackio
Prints FILENAME with its "include" and "directory" lines expanded, then prompts: "?" lists every file that was read and whether any of them changed since - the check the server makes before it reloads a configuration - "!" reads it again and "." quits. To print the expanded file only, use xymoncfg(1).

xymonavailability
Computes the availability of one status over a period, as the report pages do, and lists the color changes in that period. HISTFILE is a file in the history directory ($XYMONHISTDIR), named HOST.SERVICE with the dots in HOST written as commas. STARTTIME and ENDTIME are in Unix epoch format, as printed by "date +%s".
xymonavailability $XYMONHISTDIR/www,example,com.http 1700000000 1700086400

xymonlocator
Connects to the xymond_locator at IP:PORT and prompts for its commands. Its register, down, up and forget commands change the state of that running locator.

xymonnetprobe
Runs each network test once, the way xymonnet(1) does, and prints the result, including the banner the service sent. TESTSPEC is a service from protocols.cfg. --debug adds a trace of each step.
xymonnetprobe --debug 172.16.10.2/25/smtp
