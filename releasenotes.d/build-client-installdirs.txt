build -- a client-only build installs where it was configured to
----------------------------------------------------------------

A client-only build now installs into the INSTALLETCDIR, INSTALLBINDIR and
INSTALLTMPDIR it was configured with, which it used to ignore, and links each
moved directory back under XYMONHOME; a real directory already in the old place
is left alone, with a message. A packaging that moved the client's files by
hand can drop that step. clientupdate refuses to update a client whose bin or
etc is such a link, since tar would replace the link with a directory: update a
relocated client through its package instead.
